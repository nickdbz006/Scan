BillScanner - ứng dụng Android quét phiếu Shopee SPX (OCR offline bằng ML Kit)

Cách 1 - Android Studio: mở thư mục này -> Build > Build APK(s)
         APK: app/build/outputs/apk/debug/app-debug.apk
Cách 2 - GitHub (không cần cài gì): tạo repo, upload toàn bộ thư mục này,
         vào tab Actions > "Build APK" > tải artifact BillScanner-apk.
Cài APK: bật "Cho phép cài ứng dụng từ nguồn không xác định".
